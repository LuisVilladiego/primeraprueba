# Pinguiñoño 1.0.2 para Linux

Esta versión abre el nivel 1 y los siguientes. La aplicación que muestra «Próximamente» en el nivel 1 es la anterior.

## Instalar

En la carpeta del proyecto:

```bash
sudo apt install ./version\ linux/pinguinono_1.0.2_amd64.deb
```

Si apt dice que el archivo no es válido, el archivo no se descargó completo. Tiene que medir unos 2.9 MB y `file` debe decir `Debian binary package`.

El progreso del nivel 0 se conserva. Al abrir el roadmap, el nivel 1 muestra **Comenzar** y entra a las 9 lecciones de la terminal.
